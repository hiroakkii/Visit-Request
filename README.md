# 在宅移行初期管理 指示書作成

在宅移行初期管理料の算定に関わる「訪問薬剤管理指導に係る情報提供書 及び 指示書」を、入力補助つきで作成・印刷するブラウザアプリです。
サーバーやインストールは不要で、`index.html` をブラウザ（Chrome / Edge 推奨）で開くだけで動作します。

## 外部への通信はしません

- 患者情報を扱うため、**インターネットへの通信を一切行わない設定**にしています。
  - `index.html` の Content-Security-Policy で、同じフォルダのファイル以外の読み込み・通信（`connect-src 'none'`）・フォーム送信を禁止しています。
  - Excel読込ライブラリも `lib/` に同梱しているため、オフライン（LANケーブルを抜いた状態）でも動作します。
- 取り込んだ患者マスタ・入力中の内容・作成履歴・設定は、このPCのブラウザ（localStorage）にのみ保存されます。
  共用PCなどで残したくない場合は「保存データ消去」で削除してください。

## 使い方

1. `index.html` をブラウザで開く
2. 初回は「医療機関・医師・薬局の設定」で、医療機関名・所在地・電話/FAX、医師名、宛先の薬局を登録する
   - あわせて郵便番号データを読み込むと、住所から郵便番号を自動入力できます（下記）
3. 「患者マスタ取込（Excel）」で患者マスタ（.xlsx / .xls / .csv）を選択
   - 取込内容の確認画面で、Excelの各列がどの項目として取り込まれるかを確認（題名から自動判別。違う場合はプルダウンで変更）
   - 見出しが1行目でない場合は「見出しの行」を変更できます。シートが複数ある場合はシートを選択できます
4. 「患者情報」の検索欄で患者を検索（氏名・ふりがな・ID・住所・電話。ひらがな/カタカナ、全角/半角は区別しません）し、選ぶと
   **氏名・ふりがな・性別・年齢・住所**（列があれば生年月日・郵便番号・電話番号も）を入力します。選んだ後も手入力で修正できます
   - マスタに郵便番号の列が無い場合は、郵便番号データから住所をもとに自動入力します
5. 病名・既往歴・チェック項目などを入力。右側のプレビューに A4 1枚の指示書がそのまま表示されます
6. 「履歴に保存して印刷」で印刷（PDF保存もブラウザの印刷画面から可能）

### 入力を楽にする機能

| 機能 | 内容 |
|---|---|
| 和暦表示 | 日付は西暦で入力し、和暦（令和○年…）で印刷。生年月日は作成日時点の年齢を自動計算 |
| 指示期間 | 「1か月 / 3か月 / 6か月」ボタンで終了日を自動入力。6月を超えると警告。「指示期間を指定しない」にチェック（または日付を空欄）すると指示書に記載しません |
| 郵便番号 | 住所を入力して次の欄へ移ると、郵便番号を自動入力（郵便番号データの読込が必要）。候補が複数ある場合は選択。「住所から入力」ボタンで入力済みの郵便番号も探し直せます |
| 定型項目を既定値として保存 | 区分・宛先薬局・医師・各チェック項目・指示期間の長さ（または指定しない）を保存し、「新規作成」でその内容から開始 |
| 候補入力 | 宛先薬局・医師は設定に登録したものから選択（入力欄をクリック） |
| 作成履歴 | 印刷時に履歴へ保存。「開く」で再編集、「複製して作成」で作成日・指示期間を今日から設定し直して再発行（指示期間の更新用） |
| 入力チェック | 患者氏名・宛先・区分・指示期間・医師名の未入力や、指示期間の誤りをプレビュー上部に表示 |
| 1枚に収める | 内容が多い場合は自動で縮小して A4 1枚に収めます |
| 未選択項目の印刷 | 「選ばなかった選択肢も□で印刷」を外すと、チェックした項目だけを印刷 |

## 入力項目

添付いただいた3つの様式（訪問薬剤管理指導依頼書・情報提供書、（様式1）同、訪問薬剤管理指導に係る情報提供書及び指示書）の項目をまとめ、在宅移行初期管理に関する項目を加えています。

| 区分 | 項目 | 参考様式 |
|---|---|---|
| 基本情報 | 作成日、宛先（薬局）、指示期間（6月以内。指定しない場合は記載しない）、区分（□在宅患者訪問薬剤管理指導または居宅療養管理指導　□在宅移行初期管理料。それぞれチェックし、指示書には選んだものだけを印字） | 指示書 |
| 患者情報 | ふりがな、氏名、性別、生年月日、年齢、郵便番号、住所、電話番号（患者IDは印刷しない） | 3様式共通 |
| 介護保険・連携 | 介護度（要支援1・2、要介護1〜5 等）、介護支援専門員（氏名・所属） | 依頼書・様式1 |
| 病状・治療 | 疾病名、疾病告知（無・有）、既往歴・経過、治療状況、使用薬剤（処方せん及びお薬手帳を参照） | 3様式 |
| 在宅移行初期管理 | 在宅療養開始（予定）日、通院が困難な理由・服薬管理に係る支援が必要な状態、在宅移行初期の訪問で依頼する事項 | 追加 |
| 訪問の目的 | 服薬指導および支援／薬効・副作用の継続的チェック／ADL・QOLへの影響のチェック／その他 | 様式1 |
| 指示事項 | コンプライアンス、服薬指導（管理・保管も含む）、服薬時間、薬剤の相互作用、薬剤に影響のある食品等、処方薬以外の服用、不要薬剤の処理、副作用情報、在宅介護用品の供給・相談応需（番号は付けずに印字） | 指示書 |
| 特記事項 | 運動機能障害・寝たきり・嚥下障害・失語症・視覚障害・聴覚障害・認知症・抑うつ傾向・経管栄養・疼痛の管理・褥瘡の処置・ストーマの処置・カテーテル・点滴の管理・中心静脈栄養・その他（1つの欄にまとめて表示） | 依頼書・様式1 |
| 指示医 | 医師氏名（医療機関名・所在地・電話・FAXは設定から印字） | 3様式共通 |

「在宅移行初期管理」欄の選択肢は、在宅移行初期管理料の算定要件（対象患者・業務内容）を想定した例です。
算定要件は改定で変わることがあるため、最新の告示・通知に合わせて `app.js` の `GROUPS` で文言を変更してください。
書類の表題は設定画面で変更できます。

## 郵便番号データ（住所から郵便番号を自動入力）

アプリは外部に通信しないため、郵便番号データは一度だけ手動で読み込みます。

1. 日本郵便の「郵便番号データダウンロード」ページから、**住所の郵便番号（1レコード1行、UTF-8形式）** の `utf_ken_all.zip`
   （または従来形式の `ken_all.zip`）をダウンロードする
2. 「医療機関・医師・薬局の設定」→「郵便番号データを読み込む」で、ダウンロードした zip をそのまま選択する
3. 以後はこのブラウザに保存され（IndexedDB）、オフラインで使えます。データは毎月更新されるので、必要に応じて読み込み直してください

- 都道府県を省略した住所（「清水町八幡1」など）や、郡名を省略した住所にも対応します。同名の市区町村が複数ある場合は候補を表示します
- 丁目ごとに郵便番号が異なる町は、住所の丁目の数字から絞り込みます
- 京都市の通り名など、町名の表記が郵便番号データと異なる住所は見つからないことがあります。その場合は手入力してください
- 郵便番号データは個人情報を含まないため、「保存データ消去」では削除しません（設定画面の「郵便番号データを削除」で削除）

## 患者マスタで自動判別できる主な題名

| 項目 | 題名の例 |
|---|---|
| 氏名（必須） | 氏名、患者名、患者氏名、名前、利用者名 |
| ふりがな | ふりがな、フリガナ、カナ、氏名カナ、よみがな |
| 性別 | 性別、性、男女（値は 1/2、男/女、M/F に対応） |
| 年齢 | 年齢（生年月日がある場合は生年月日から計算） |
| 住所 | 住所、現住所、所在地（＋ 住所2、番地、建物名、方書 を後ろに連結） |
| 生年月日（任意） | 生年月日、誕生日（Excelの日付、2000/1/2、20000102、昭和25年3月4日、S25.3.4 などに対応） |
| 郵便番号・電話番号（任意） | 郵便番号、〒／電話、電話番号、TEL |
| ID（任意） | 患者番号、患者ID、カルテ番号 |

保険者番号などその他の列は取り込みません。判別キーワードは `master.js` の `FIELDS` で変更できます。

## ファイル構成

- `index.html` / `style.css` … 画面・印刷レイアウト
- `app.js` … 入力フォーム、指示書の組み立て、設定・既定値・履歴
- `master.js` … 患者マスタ（Excel）の取込・検索
- `zipcode.js` … 郵便番号データの読込・住所からの郵便番号検索
- `util.js` … 文字列・日付・和暦の共通処理
- `lib/xlsx.full.min.js` … Excel読込ライブラリ [SheetJS](https://sheetjs.com/) 0.18.5（Apache License 2.0、`lib/xlsx.LICENSE`）
- `sample/患者マスタ_サンプル.xlsx` … 動作確認用の架空データ（表題行・不要列・和暦の生年月日・年齢のみの行などを含む）
